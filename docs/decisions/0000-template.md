# NNNN — Tên quyết định ngắn gọn

- **Trạng thái**: Đề xuất / Đã áp dụng / Đã thay thế bởi 00XX
- **Ngày**: YYYY-MM-DD
- **Phase liên quan**: Phase N

## Bối cảnh

Vấn đề gì cần quyết định, và tài liệu gốc (`bao-cao-ky-thuat.md` /
`de-xuat-trien-khai.md`) nói gì về việc này — trích mục cụ thể nếu có.

## Quyết định

Chọn phương án nào, mô tả cụ thể (file/service/thư viện thay đổi).

## Lý do

Vì sao chọn phương án này thay vì phương án trong tài liệu gốc — đánh đổi
đã cân nhắc.

## Hệ quả

- Ảnh hưởng gì tới checklist các phase khác trong `de-xuat-trien-khai.md`
  (mục nào coi như xong sớm/bỏ qua, mục nào phải làm khác đi).
- Ảnh hưởng gì tới nguyên tắc kiến trúc trong `CLAUDE.md`/`bao-cao-ky-thuat.md`
  mục 10.1 (nếu có ngoại lệ mới, ghi rõ ở đây).

## Tham chiếu

Đường dẫn file code liên quan, module doc liên quan trong `docs/modules/`.
